What does URLdecode show you?
Every URL is made up of several parts — the protocol, domain, path, and query parameters. Query parameters (everything after the ?) are often where tracking codes, session identifiers, and analytics data live. URLdecode reads all of it and explains each piece in plain English.
⚗️ Advanced Analysis Mode
⚠️ Resource Warning
This feature downloads the Pyodide WebAssembly Python runtime — approximately 10–15 MB of data. It runs entirely in your browser; nothing is sent to any server.

What it does: Runs a Python script in your browser using WebAssembly to perform deeper analysis on each URL parameter, detecting things the standard parser misses:

  • Nested JSON hidden inside base64-encoded values
  • JWT tokens — decodes the header & payload automatically
  • Hex-encoded strings decoded to readable text
  • Multiple layers of URL-encoding unwrapped step by step
  • UUID format & version identification
  • Precise Unix timestamp decoding (seconds & milliseconds)
⏱ How long will it take?
The first load downloads ~10–15 MB and usually takes 15–45 seconds depending on your connection. Once loaded it stays cached in your browser, so subsequent uses on the same page are instant.
